# Sample Superstore Sales Performance Dashboard

## 📌 Project Overview

The **Sample Superstore Sales Performance Dashboard** is an interactive business analytics project developed using **Microsoft Power BI**.

The dashboard is designed to help management quickly understand sales performance across **products, categories, and regions** and identify key business patterns for better decision-making.

---

## 🎯 Objective

The objective of this project is to:

- Analyze sales performance across products.
- Compare sales performance across categories.
- Analyze sales performance across regions.
- Identify key business patterns from sales data.
- Develop an interactive Power BI dashboard.

---

## 📂 Dataset

**Dataset:** Sample Superstore  
**Source:** Kaggle  
**Power BI Table:** `Sample_ Superstore`

### Key Fields

- Product Name
- Category
- Region
- Sales
- Order Date

---

## 🛠️ Tools & Technologies

- **Microsoft Power BI**
- **Power Query**
- **DAX**
- **Kaggle Sample Superstore Dataset**

---

## 📊 Dashboard Visualizations

### 1. Sales by Products

A product-wise sales visualization is used to identify the **highest-selling products**.

### 2. Sales by Categories

A category-wise visualization is used to compare sales performance across different categories.

### 3. Sales by Regions

A regional sales visualization is used to compare sales performance across different regions.

---

## 🎛️ Interactive Features

The dashboard includes interactive slicers for:

- **Region**
- **Category**
- **Order Date**

These filters allow users to dynamically explore sales performance based on selected regions, categories, and dates.

---

## 💡 Key Business Insights

The dashboard enables management to:

- Identify the **highest-selling products**.
- Determine the **best-performing category**.
- Identify the **highest and lowest-performing regions**.
- Explore sales performance using interactive filters.
- Identify important patterns in sales data.

## 📈 Dashboard Output

The completed dashboard provides:

- Product-wise Sales Analysis

- Regional Sales Performance
- Interactive Filters and Slicers
- Key Business Insights
